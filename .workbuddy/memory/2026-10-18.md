## 交易体系体检（用户「检查体系还有什么遗漏或没考虑到的」）

用真实样本（25690 条 signal_outcomes，2025-02-07~2026-10-15）对当前体系做压力测试，挖出 8 个盲区，其中 3 个致命。全部结论见 `.workbuddy/artifacts/交易体系体检报告.md`。

### 三个致命发现（数据背书，别当成小问题）

1. **标签错位——体系优化错了目标**
   - 体系用 `max_return≥10%`（20日内结构有没有拉起来）训练，但用户真正要的是「拿到手的钱」。
   - 决定性检验：体系分档 × **卖点出场收益**（正确标签）——D档(≥0.3)出场收益中位 5.51%、胜率 68.2%，**反而低于** A档(<0)的 6.17%、74.6%。**体系分越高，用正确出场方式赚得越少。**

2. **D档高分是右偏幻觉**
   - 期末收益：A档中位 -0.40% 均值 +0.88%；D档中位 **-0.61%（比A还差）** 均值 +2.60%。
   - 均值全靠 P90 的 +29.4% 拉动——典型「少数暴涨股撑门面」，多数 D 档票实际亏钱。
   - D档回撤更大：中位 -9.4% vs A档 -5.6%，最差档 -24.5%。高分 = 高波动 = 高回撤。

3. **超额收益(alpha)≈0**
   - 个股期末收益 − 同期上证涨跌：D档跑赢大盘 **44.9%**，A档 **45.0%**——体系分对「跑赢大盘」毫无贡献。
   - D档 74.7% 是三买：体系本质学到了「押注三买」，不是多维特征的真区分。

### 五个其他盲区

4. **卖点出场完胜固定20日**：有卖点出场的样本 平均 +12.65% vs 20日持有 +3.55%，胜率 73.9% vs 57.3%，67.4% 情况下卖点出场更好。缠论卖点本身就是优秀出场信号，体系完全没用上。
5. **20日窗口有截断**：11.1% 样本峰值恰好在第20天，P25=19（四分之一样本窗口末尾还在涨被砍）。
6. **样本期是单边牛市**：上证 3304→3707 (+12.2%)，熊市/震荡市表现未知，体系可能只是「牛市 beta」。
7. **没算交易成本**：A股佣金+印花税+过户费约单边 0.1%，高频换仓会吃掉薄利。
8. **体系分没有置信区间**：1974 条 D 档样本看着多，但分箱后单箱可能 <30，增益是点估计无区间。

### 体检方法（可复用）
- 体系分档：`score_signal(feats, snap)` 后按 <0 / 0~0.15 / 0.15~0.3 / ≥0.3 分四档。
- 出场收益：买点 signal_date 之后第一个 FIRST_SELL/SECOND_SELL 的 price/信号价-1。
- alpha：个股 hold_return − 同期(sh000001 fq='ref') 20日涨幅，bisect 对齐日期。

### 待用户定夺的改进方向（未编码）
- 标签从 max_return 改成「卖点出场收益」或「风险调整收益(收益/回撤)」重训体系。
- 体系分加 alpha 口径（跑赢大盘才算数）。
- 出场模块：把卖点从「风险提示」升级为「建议出场价」，池/选股页给目标价+止损价。
- 分箱加样本数与置信区间标注，小样本箱不给分。
- 样本期做牛熊分段验证（当前只有牛市段，需等数据积累或补历史）。

   幂等迁移 `_migrate_outcomes_exit_columns`（真实库副本验证 25690 行无损）。
2. **Service**：`_compute_outcome` 规则化出场——信号后 60 交易日（EXIT_WINDOW_BARS）内首个卖点出场，
   否则末根收盘强平（FLAT_CLOSE）；净收益扣 TRADE_COST_ROUNDTRIP=0.16%；alpha 减同期上证（fq='ref'）。

   修复为「卖点必须落在 exit_window 内」，测试 `test_sell_outside_window_becomes_flat_close` 锁死。
   全量重算 17 秒，25634 条全部带出场+alpha。
3. **体系引擎（trading_system.py 重写）**：
   - 标签换 `net_exit_return ≥ 5%`（DEFAULT_WIN_THRESHOLD=0.05），兼容 v1 老样本退回 max_return。
   - `gain_lower_bound`：两比率差（箱胜率 vs 其余样本胜率）的 SE 折减下界。**踩坑**：
     最初对单比率用 Wilson 下界再减基准——会把 n=25000 的基准误差也算进去，69 箱只剩 11 箱为正。
   - `score_signal` 非对称打分：下界>0 的正箱加分、表面负+下界负的负箱扣分、中间地带（下界≤0 表面≥0）不加减。
     **踩坑**：全量求和版本让 96% 样本挤在负分区间，验证段 0 条正分。
   - `validate_time_split` 分组从三等分改为「体系分≥0 vs <0」。**踩坑**：重尾分布下三等分把 7500 条负分均摊进高分组，
     掩盖真实区分（三等分 spread=-0.22 vs 按符号分组前测是正的）。
   - `market_regime` + `validate_by_regime`：按指数 20 日涨跌+宽度分上行/下行/震荡/弱市，分段验证。
   - `system_validate` 返回 `robust`（时间分割+全部可验证状态都有 edge）。
4. **池/选股挂交易指令**：`stop_price`（=anchor_price 结构锚点，跌破即买点失效）+
   `expected_exit`（体系分档历史出场收益中位数，档样本 <30 不给数）。
5. **前端**：选股表加止损价/期望出场两列（含排序标量 expected_exit_value，防对象排序）；
   池表胜算列加 🛡 tooltip（止损+期望出场）；体系分 tooltip 显示表面/保守双增益+样本数；
   验证卡两档渲染+出场中位线+分市场状态表；增益条形图按保守增益排序。
6. **测试**：`tests/test_system_v2.py` 20 例（Wilson/标签/分段/出场计算/止损挂载）。

### 严格验证的结果（必须诚实面对）

**工程全部就位，但当前 18 特征在「出场净收益」标签下，严格时间外推没有 edge**：

- 验证段（后 30% 样本，时间严格后置）：体系分≥0 组 n=10 胜率 30%，<0 组 n=7681 胜率 30.4%，spread≈0。
- 分市场状态：震荡段 spread=-0.17、弱市段 spread=-0.015，均无 edge。
- **为什么之前 `/tmp/verify_v2b.py` 显示 +16%/78%？前视偏差**：那次用全样本算的增益打分——
  验证段的信息泄漏进了打分。严格 train/test 切分后幻觉消失。这正是体检报告的精神：
  v1 的「spread=0.20」很可能是同一种前视 + 标签错位的产物。
- 另一个结构性发现：特征箱表面增益普遍只有 +0.01~+0.08，而两比率差 SE 在大样本下约 ±0.008~0.02，
  保守下界后大多数箱子「证据不足」。**要让体系立得住，需要的是更强区分度的特征（比如结构类：
  中枢位置、笔级别、次级别共振），而不是继续调统计口径。**

### 现在体系的正确用法

- 体系分≥0 = 「历史上这套规则确信净赚钱的结构」，是**必要条件**而非充分条件——正分极少（严格外推下约 0.1%），
  拿它当「强推荐」会失望；拿它当「过滤明显差的票」仍有价值（<0 组出场中位 -1.06% vs 全体 +0.55%）。
- 止损价（结构锚点）与出场规则（60 日内首个卖点/强平）与体系分数无关，**无论分数如何都应遵守**——
  这是本次改造中最确定有价值的部分（卖点出场完胜固定持有是 15465 条样本的强结论）。
- 快照表里 has_edge=False / robust=False 是诚实的健康指标：什么时候变 True，体系才算真正「自成长」起来了。

### 关键判断（别改回去）
- 验证必须严格时间分割，任何「全样本打分再分组」的验证都有前视偏差，会自动产出好看的假象。
- 打分、验证分组的口径必须与体系分语义一致（≥0 vs <0），不能机械三等分。
- 出场计算窗口必须夹紧（窗口外卖点不算），这类 bug 单测很难想到，冒烟测试用真实数据才能抓到。

## 体系 v3：缠论结构特征 → 严格验证首次 has_edge=True

用户「继续」= 落地结构类特征。从 signals.meta 提取 6 个结构特征（全部只用信号时刻数据）：
- `zs_position`（买点在中枢 [zd,zg] 的归一位置：<0 下方=一买区、>1 上方=三买区）
- `zs_height_pct`（中枢高度/价格，整理规模）
- `seg_effort_ratio`（当前段/前段力度比，背驰衰减连续量）
- `seg_range_pct`（当前段振幅/价格，段深度）
- `breakout_strength`（三买突破高点越中枢上沿幅度）
- `structure_level`（leg/pen）

meta 覆盖率：一买 13863 有 zhongshu、三买约 7800 有 breakout_high、段数据约 9000。

### 严格验证结果（70/30 时间后置，训练段算增益、验证段只打分）

| 指标 | v2（纯指标特征） | v3（+结构特征） |
|---|---|---|
| 体系分≥0 组标签胜率 | 17.2% (n=383) | **44.4% (n=9)** |
| <0 组 | 19.4% | 30.4% |
| spread | -0.4pt（无 edge） | **+14.1pt，has_edge=True** |
| 弱市分段 | 无 edge | **edge=True（+6.8pt）** |
| 震荡段 | 无 edge | -0.4pt（无 edge）→ robust 仍 False |

分层还显示 `-0.10~-0.02`（体系确信的差结构）胜率仅 22.9%——**排除价值**已经很强。

### 诚实备注
- 正分样本仅 9 条，统计功效低；spread +14.1pt 有运气成分的可能。震荡段仍无 edge，robust=False。
- 但方向性证据链完整：结构特征下界增益为正（zs_position 最佳箱 +0.023）、正分样本跑赢、
  差结构箱显著跑输——符合缠论「结构决定胜负」的先验。
- 下一步提升样本：数据积累 + 三买 segment meta 覆盖率提升后自然改善，不需再改代码。
