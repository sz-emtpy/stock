## 二、必须诚实告诉你的事

工程全部落地之后，**严格时间分割验证揭示了一个比体检报告更深的问题**：

### 当前 18 个特征，在「出场净收益」标签下，时间外推没有 edge

| 验证口径 | 结果 |
|---|---|
| 严格时间分割（训练 17943 → 验证 7691，时间严格后置） | 体系分≥0 组胜率 17.2% vs <0 组 19.4%，**无 edge** |
| 分市场状态 | 震荡段 spread=-0.17、弱市段 -0.015，均无 edge |
| `robust`（综合稳健性） | **False** |

### 为什么之前「看起来有效」？

1. **v1 的 spread=0.20 是前视偏差 + 标签错位的合成幻觉**——用全样本算增益再分组验证，验证段的信息泄漏进了打分；标签又在优化「冲高」而非「到手」。
2. **v2 调试过程中也复现了一次同样的幻觉**（全样本打分显示高分档 +16.5%/78.3%），切换到严格 train/test 切分后消失。这不是巧合，是方法论的胜利：**只要验证方法对了，好看的数字就消失了**。

### 结构性根因

特征箱的表面增益普遍只有 +0.01~+0.08，而大样本下两比率差的置信区间约 ±0.01~0.02——**绝大多数箱子撑不起统计显著的 edge**。18 个指标类特征（量比/RSI/KDJ/波动率…）在 25000 样本上就是这样：单箱信息量太小，叠加后仍不足以跨期稳定。

**要让体系真正立得住，需要的是更强区分度的特征，不是继续调统计口径。** 最有希望的方向是缠论结构类特征：

- 买点在**日线中枢**的位置（中枢上沿/下沿/内部/突破）
- 买点的**笔/段级别**与中枢规模
- **次级别（30 分钟）区间套共振**的有无（区间套确认过的买点 vs 未确认的）
- 前一个同级别中枢的**盘整/趋势**属性

这些特征在数据里已经有一部分（meta 里的 previous_segment/current_segment、区间套结果表），落地成本中等。

## 三、这次改造里确定有价值的东西（无论体系分数如何都建议遵守）

1. **出场规则**：60 个交易日内出现首个缠论卖点 → 按卖点价离场；否则窗口末强平。
   依据：15465 条样本，卖点出场平均 +12.65% / 胜率 73.9%，完胜固定持有 +3.55% / 57.3%。
2. **止损价 = 结构锚点**（一买=背驰低点、二买=回调低点、三买=中枢上沿）：跌破即买点前提失效，
   这是缠论原文的止损逻辑，现在每行池/选股数据都带 `stop_price`。
3. **交易成本意识**：所有收益口径现在都是**净收益**（扣 0.16% 往返成本）。
4. **诚实的验证面板**：体系页现在显示 `has_edge` / `robust` / 分市场状态表——什么时候变 True，
   体系才算真正立得住。**目前是 False，不要基于体系分做重仓决策。**

## 四、使用建议

| 场景 | 建议 |
|---|---|
| 体系分 ≥0 的票 | 极少（严格外推下 ~0.1%）。可作为「精选观察」，小仓位试探，严格按止损价执行 |
| 体系分 <0 的票 | 不建议买（出场中位 -1.06%），体系在这里仍有过滤价值 |
| 所有买入 | 必须带止损价（列表已给），跌破锚点无条件离场 |
| 持仓 | 按出场规则执行：出现一卖/二卖离场，60 交易日无卖点也强平 |
| 体系重建 | 每天收盘扫描后跑一次 rebuild；`has_edge` 变 True 前不加仓 |

## 七、v3 增补：结构特征让体系首次立住（同日追加）

体检报告建议的方向（结构类特征）当天落地，从 signals.meta 提取 6 个缠论结构特征：
中枢位置/中枢规模/段力度比/段深度/突破强度/结构级别（全部只用信号时刻数据，防未来函数）。

**严格时间分割验证（训练 17943 → 验证 7691，时间后置）**：

| 指标 | v2（纯指标特征） | v3（+结构特征） |
|---|---|---|
| 体系分≥0 组标签胜率 | 17.2% | **44.4%** |
| <0 组 | 19.4% | 30.4% |
| spread | 无 edge | **+14.1pt，has_edge=True** |
| 弱市分段 | 无 edge | edge=True |

另发现排除价值：体系分 -0.10~-0.02 的「确信差结构」胜率仅 22.9%。

**注意**：正分样本仅 9 条（统计功效低）、震荡段仍无 edge（robust=False）——方向正确但还未到
「可以重仓跟随」的程度。每天收盘扫描 + rebuild 后，样本自然积累，验证面板会持续更新。

## 八、v4 收尾批次（同日）

- **每日流水线** `scripts/daily_pipeline.py`：scan → m30 增量（可跳过）→ rebuild → 重评关注圈，
  单步独立容错，cron 一条命令替代手工四步。
- **次级别可得性特征**（`sublevel_available`）：开发中曾把「确认成功」直接当特征，
  复查发现是未来函数后撤回，只保留合法的「数据可得性」。
- **周线中枢约束**（高级别递归 v1）：日线重采样周线 → 引擎取中枢，只认信号日前已完成的
  周线中枢。**新发现：周线特征是强排除信号**——「周线远低于中枢」下界 -0.18、「周线空头」
  -0.26、「周线走平」-0.22（合计 ~7400 条样本），「大级别定方向」的量化证据。
- v4 严格验证：has_edge=True（spread +9.6pt），robust=False（震荡段）；463 例全绿，快照 id=9。
- 特征总数 27。
